# Proton.ai

> Proton.ai is an AI-powered industry cloud platform for wholesale and B2B distributors. It centralizes a distributor's customer, product, and transactional data and applies deep-learning models to deliver real-time product recommendations and automate CRM, e-commerce, order, and quote workflows. Proton.ai exposes an AI REST API (documented via Postman) that returns product recommendations and performs platform actions, authenticated with a static API key in the request header. Boston-based; $20M Series A led by Felicis Ventures.
